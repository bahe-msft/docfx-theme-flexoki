## Features

Flexoki for DocFX brings [Steph Ango's Flexoki palette](https://stephango.com/flexoki) and the design ideas of [Starlight Flexoki](https://github.com/delucis/starlight-theme-flexoki) to DocFX's modern template. Warm paper, restrained typography, and a cyan accent make long-form guides and API references feel at home together.

- **Light and dark:** Follows your system setting, with DocFX's built-in theme picker.
- **Native DocFX:** Navigation, search, accessibility controls, and API reference pages stay intact.
- **CSS-first:** No Astro runtime, custom rendering pipeline, or external fonts.

Browse the [showcase](articles/showcase.md) or the [generated API reference](xref:Flexoki.Sample.Swatch).
